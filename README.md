# To-Do List Manager

A simple C# console application for adding, removing, and listing tasks.

## Run

Install the .NET 10 SDK, then run:

```sh
dotnet run --project todo/todo.csproj
```

Choose an option from the menu to add a task, remove a task by its number, list tasks, or quit. Tasks are stored in memory and are cleared when the program exits.

The source includes comments explaining the main parts of the program.
